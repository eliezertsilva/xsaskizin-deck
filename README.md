# xSaskizin Deck

App Android para controlar o OBS pelo celular (OBS WebSocket v5), com a identidade do canal xSaskizin.

- Troca de cenas, live, gravação e clipe (replay buffer)
- Câmera da Gameplay em 4 cantos (câmera + moldura + painel do chat, com os itens do LivePix trocando de lado)
- Áudio e fontes por cena, com modo de edição (✎) para escolher o que aparece em cada cena
- Conecta direto no OBS pela rede Wi‑Fi, sem servidor no PC

## Instalar
Baixe o `xsaskizin-deck.apk` da última Release no celular e instale (permita "instalar apps desconhecidos" para o navegador).

## Build
Todo push na `main` gera o APK pelo GitHub Actions (`.github/workflows/android.yml`) e publica em Releases.
